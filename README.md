# JPEG Viewer - Shortcut Guide

## Keyboard Shortcuts

| Action | Shortcut |
|---|---|
| Open File | `Ctrl + O` |
| Next Image | `Right Arrow` or `D` |
| Previous Image | `Left Arrow` or `A` or `Q` |
| Zoom In | `+` |
| Zoom Out | `-` |
| Reset Zoom | `W` or `Up Arrow` or `Down Arrow` |
| Fit Image to Window | `S` or `Down Arrow` or `Numpad 0` |
| Toggle Fullscreen | `F11` or `Enter` or `F` |

---

## Mouse Controls

| Action | Mouse Input |
|---|---|
| Open File | Double-click Left Mouse Button |
| Fit Image to Window | Double-click Right Mouse Button |
| Toggle Fullscreen | Click Middle Mouse Button |

---

## Mouse Wheel

The mouse wheel can be used for either image navigation or zooming.

### Normal Mode
| Input | Action |
|---|---|
| Scroll Up | Previous Image |
| Scroll Down | Next Image |

### Zoom Mode
When zoom mode is active:

| Input | Action |
|---|---|
| Scroll Up | Zoom In |
| Scroll Down | Zoom Out |

---

## Tips

- Mouse actions only work when the cursor is over the image area.
- `Ctrl + O` opens the file picker.
- Fullscreen can be toggled quickly using `F11`, `F`, `Enter`, or the middle mouse button.
