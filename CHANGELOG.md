# Changelog

- Pop-out Ball dragging now delegates native window movement to the compositor to avoid pointer/window-position feedback jitter; physics pauses while dragging and resumes at rest.
- Added shared monitor selection and a manual rotation-angle control in the Pop-out settings deck.
- Pop-out settings frame fills now derive from the active egui theme visuals instead of fixed dark colors.

## Unreleased
- Moved Pop-out controls into a docked right-hand sidebar opened from an Image tab's POP-OUT ON/OFF status button (including the custom title-bar tab row). Ball dragging now uses per-frame pointer-position deltas instead of cumulative drag displacement, preventing throw acceleration and window jitter. The minimized root viewport now wakes periodically during Pop-out physics and exits its minimized fast path on focus or pointer/key input after restoration.
- Fixed JVP preset compilation visibility and removed unused mutable bindings and obsolete dead code; the Linux-only global-pointer capability check is no longer compiled on Windows.
- Pop-outs now use deferred child viewports with independent rendering while the main window is minimized. On Windows, the pop-out native owner relationship is detached so minimizing the main window does not automatically hide its floating image windows. Root-side viewport-level/transparent commands are no longer redundantly sent each frame.
- Opening an Image tab now expands the shared full-image LRU by one slot per open Image tab before snapshotting the outgoing image. Cache cleanup pins the stable static-image IDs for all open Image tabs and the primary Browse preload window, preserving loaded textures when switching between tabs or pausing normal Browse speculation. GIFs continue to use their animated decode path. Closing tabs releases their reserved slot.
- The Image-tab Pop-out controller has a larger ON indicator and immediate size-slider resizing. General opacity now applies immediately; only Pass pointer-triggered opacity transitions are eased. The controller and image viewport use the measured CentralPanel width rather than a partially consumed wrapped-layout width.
- Expanded the Image-tab Pop-out control deck with a more spacious cockpit-style layout and a dedicated Tricks section. Ball mode now uses a fixed-step 2D rigid-disk simulation: rotation is seeded from throw velocity, surface friction applies tangential contact impulses that couple translation and spin only on impacts, and in-air velocity is not damped. DVD random rotations ease toward their new angles instead of snapping instantly.
- Each Pop-out opening now receives a unique deferred-viewport ID. Closing and reopening an Image tab's pop-out therefore creates a new native window instead of attempting to reuse an egui viewport that has already been closed; options are preserved when the native close button is used.
- Fixed the pop-out hover-toolbar close action so it notifies the root manager before closing the native viewport; the controller can now reopen the pop-out after it has been closed. Rebuilt the central image viewport rectangle from the actual CentralPanel bounds so workspace-tab layout does not incorrectly reduce its viewer width. Ball contacts now suppress tiny restitution rebounds to prevent persistent micro-hopping while retaining contact-only friction.
- Added versioned `.jvp` Pop-out presets. Presets can bundle the current image or animation, link to its file/archive entry, or save options only; loading offers to open the linked or bundled image or apply options alone. Linked archive entries are validated without decompressing them, bundled images are format-checked and extracted to the application cache, and saves use a temporary archive plus backup/restore so an interrupted save does not destroy an existing preset.
- Renamed the DVD controls drawer to Tricks while keeping the DVD effect. Added optional circular collision bounds, random reflection/rotation after impacts, timed random bounce, and a Ball mode with gravity, bounciness, drag-and-throw movement, and optional spin. Native Wayland uses compositor-managed manual dragging but does not support the absolute positioning required for automatic DVD/Ball motion.
- Always-on-top pop-outs now yield their topmost level while the main application is focused, allowing the main window to be raised normally, and restore topmost status when the main app loses focus. Added a bounds overlay that is independent of Pass mode.
- Made `WorkspaceManager::active_tab` crate-visible so the Browse sidebar can inspect the active workspace tab without exposing the method publicly outside the application crate.
- Browse now reuses the existing image tile for an open Image tab, showing a tab indicator, pop-out indicator, and close control without duplicating thumbnails. Image tabs outside the Browse collection appear as ordinary tiles in the same grid.
- Pop-out move and resize hit regions no longer overlap: each of the eight edge/corner handles owns its own input area, custom aspect-ratio resizing is no longer competing with native window resizing, and the window builder supplies initial geometry only once.

- Added an Image-tab Pop-out settings sidebar and dedicated `src/app/popout/` subsystem for undecorated floating image windows, click-through, image opacity, DVD-style monitor-bounded movement, monitor selection, DVD speed and per-edge offsets, aspect-ratio-preserving size, drag-anywhere movement, four-edge/four-corner resize, stay-on-top/bottom and hover-only close/stacking controls, and tab-linked window lifetime. Animated GIF frames are shared between animation states so pop-outs can loop at the tab's playback speed without duplicating the decoded frame buffers.
- Fixed the Browse sidebar context menu so Share and the other actions are presented in one popup.
- Added a direct Compare button to the desktop menu bar and hamburger menu. Compare now starts with at least two panes, supports image drag-and-drop, and can add multiple images through the file picker.
- Masonry now scrolls to the image that was active when it opened and marks it with an eye badge. Loaded folder collections update when files are moved between folders or sent to the trash.
- Moving an image out of the currently loaded Browse folder now removes it from the sidebar when its destination folder is not loaded; already-loaded destination folders receive moved entries.
- Compare now owns image drops throughout its workspace (except explicit Queue/Favorites drops), preventing dropped files from replacing the main Viewer image.
- Added right-click entry actions to the main image view, matching the single-entry operations available in Sidebar and Masonry.
- Added per-split Compare context actions for anchors, pan/zoom and rotation alignment, view reset, split synchronization, image replacement, and opening or closing splits. Consolidated global synchronization controls under one “Sync:” label.
- Masonry Ctrl+click now always enables Select mode and toggles the clicked entry; while Select mode is active, plain clicks also toggle selection. The current image has a centered eye marker, while hover highlighting and multi-selection remain independently visible.
- Main Viewer double-left-click now fits the current image (the former double-left-click Open File gesture is removed). Pan clamping now uses 20% of the smaller of the image and viewport dimensions, preventing inverted bounds on zoomed-in images, and is reapplied after pointer, wheel, keyboard, and animated zoom changes.
- Added Compare access from Browse, Queue, Favorites, and Masonry entry context menus. Sidebar images can also be dragged directly into a specific Compare split.
- Added a Masonry button to the Compare toolbar, direct anchor placement at the right-click position, and per-split earlier/later/first/last ordering actions. Reset View preserves anchors; Clear Anchors remains separate.
- Masonry hover highlighting is now available on the current image, and its eye marker is centered without suppressing the selected-entry indicator.

- Fixed Pop-out resizing: non-overlapping move and eight edge/corner resize hit regions prevent egui pointer capture conflicts; OS-native resizing is disabled so custom aspect-ratio resizing owns window geometry. Initial viewport geometry is supplied once, and later size/position changes use one command path. The size slider now applies native window resizing continuously while dragging.
